# Dragon

  A 3D browser-based flying game built with Three.js. Fly through a sky sphere, roll/pitch/yaw around, collect gold
  coins, and grow your dragon's tail — avoid your own tail and the "farts" it leaves behind as trail hazards, or
  it's game over.

  ## Controls

  - **Up/Down Arrow** — pitch
  - **Left/Right Arrow** — roll
  - **a/d** — yaw

  ## Running Locally

  **Requirements:** [Node.js](https://nodejs.org/) installed

  1. Clone the repo
     ```
     git clone https://github.com/TigerSharkActual/dragon.git
     ```
     ```
     cd dragon
     ```
  2. Install dependencies
     ```
     npm install
     ```
  3. Start the dev server
     ```
     npm run dev
     ```
  4. Open the local URL printed in the terminal (usually `http://localhost:5173`)

  ## Built With

  - [Three.js](https://threejs.org/) — 3D rendering
  - [Vite](https://vitejs.dev/) — dev server / build tool
